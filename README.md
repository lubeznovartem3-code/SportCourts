## О проекте

SportCourts — мобильное приложение для поиска спортивных площадок и организации совместных игр. Оно предназначено для людей, которые занимаются спортом на открытых площадках и хотят находить места для тренировок и единомышленников.

Приложение позволяет просматривать спортивные площадки на интерактивной карте, отмечать своё присутствие на выбранной площадке, узнавать количество находящихся там пользователей, добавлять друзей и находить открытые игры, к которым можно присоединиться.

Основная цель проекта — упростить поиск спортивных площадок, помочь пользователям находить компанию для совместных занятий и сделать занятия спортом более доступными и удобными.

Проект ориентирован на любителей активного образа жизни, студентов, школьников и всех, кто заинтересован в совместных занятиях спортом.
